# 官网 SEO 单页矩阵开发记录

- 日期：2026-06-27
- 项目：`frontend-user-v3-www`
- 类型：官网 SEO / 公开落地页 / sitemap 与预渲染
- 状态：已实现，持续 SEO 优化中

## 背景

www 端原本已有基础 SEO 能力：`index.html` 默认 meta、路由 meta 同步、`sitemap.xml`、`robots.txt` 与公开页预渲染脚本。但收录入口主要覆盖首页、产品页、关于、公告、帮助等基础公开页，缺少面向搜索流量的关键词落地页。

本次目标是在不引入 Nuxt、不改 SSR、不新增后端接口的前提下，新增一组可被搜索引擎收录的静态专题页，并让路由、sitemap、预渲染和页脚内链共用同一份 SEO 配置。

## 实现内容

### 1. SEO 单页配置

新增 `frontend-user-v3-www/src/data/seoLandingPages.js`，集中维护 SEO 页面数据：

- `path`
- `title`
- `description`
- `keywords`
- `hero`
- `features`
- `scenarios`
- `faqs`
- `relatedLinks`
- `cta`

首批页面：

| 路径 | 主关键词 | 页面定位 |
| --- | --- | --- |
| `/cloud-server` | 云服务器 | 标准云主机与弹性计算 |
| `/hong-kong-server` | 香港服务器 | 跨境访问、亚太业务、外贸站点 |
| `/us-server` | 美国服务器 | 海外部署、海外网站、跨境业务 |
| `/high-defense-server` | 高防服务器 | 游戏、接口、活动站等防护场景 |
| `/cloud-pc` | 云电脑 | 远程办公、轻量桌面、软件测试 |

### 2. 路由与运行时 meta

`frontend-user-v3-www/src/app/router/routes.ts` 从 SEO 配置生成固定公开路由，统一指向 `src/pages/website/seo-landing/index.vue`。

`frontend-user-v3-www/src/utils/pageMeta.js` 新增 `keywords` 同步能力，SEO 页可在 SPA 路由切换时输出独立：

- `title`
- `description`
- `keywords`
- `canonical`
- `og:title`
- `og:description`
- `og:url`

`frontend-user-v3-www/src/app/router/guards.ts` 增加默认公开站点域名 `https://www.coyjs.cn`，避免运行时 canonical 在未配置 `VITE_PUBLIC_SITE_URL` 时退化成相对路径。

### 3. sitemap 与预渲染

`frontend-user-v3-www/scripts/generate-sitemap.mjs` 接入 `listSeoLandingSitemapRoutes()`，构建后自动把 5 个 SEO 单页写入 `dist/sitemap.xml`。

`frontend-user-v3-www/scripts/prerender-www.mjs` 接入同一份 SEO 路由数据，构建后生成：

- `dist/cloud-server/index.html`
- `dist/hong-kong-server/index.html`
- `dist/us-server/index.html`
- `dist/high-defense-server/index.html`
- `dist/cloud-pc/index.html`

静态 HTML 均写入独立 title、description、keywords、canonical。旧公开页没有专属 keywords 时继续保留模板默认 keywords，避免误清空现有 SEO meta。

### 4. 页面与内链

新增统一 SEO 页面模板 `frontend-user-v3-www/src/pages/website/seo-landing/index.vue`：

- 首屏 H1、摘要、标签、CTA
- 视觉资产复用 `public/img/website/solutions/*.svg`
- 产品价值卡片
- 适用场景
- FAQ
- 相关内容链接
- 底部 CTA

`frontend-user-v3-www/src/layout/WebsiteLayout.vue` 的页脚产品列改为从 `seoLandingFooterLinks` 渲染，给 SEO 单页提供真实站内链接。

### 5. 参考 idcmax 风格重写

根据 `https://idcmax.com/` 当前可抓取页面的云服务门户风格，二次重写 `frontend-user-v3-www/src/pages/website/seo-landing/index.vue`：

- 保留 5 个 SEO 页面共用一个模板、共用 `seoLandingPages.js` 配置的架构。
- 首屏改为浅蓝科技横幅，增加左侧竖向卖点导航、关键词摘要、H1 与 CTA。
- 首屏不再使用独立资源摘要/插画卡片，避免出现与产品无关的泛化卡片视觉。
- 首屏底部增加四列能力条，其中前三列来自当前页面 `features`，第四列承接当前页面 CTA。
- 产品区改为居中标题、分类 tab、小型产品卡横向排列的云厂商产品矩阵样式。
- 场景区改为深浅蓝背景 + 左侧场景列表 + 右侧方案说明面板，强化搜索用户进入后的选型路径。
- 新增开通流程区：查看产品、确认配置、注册开通、持续维护。
- FAQ 与底部 CTA 保留，样式统一为轻边框、蓝白色、低阴影的 IDC 云服务页面风格。

后续按页面视觉反馈调整：

- 移除首屏右侧资源摘要/插画卡片，SEO 单页首屏改为单列内容横幅。
- 下方服务摘要区改为承接不同商品配置里的 `features` 与 `cta` 内容。
- 最新调整后，页面仍保持“一个 Vue 模板 + 一份页面配置”的结构；不同商品页只改 `seoLandingPages.js` 里的内容字段。

### 6. SEO 技术优化

在已有 SEO 单页矩阵基础上继续优化搜索引擎可读性：

- `frontend-user-v3-www/index.html` 增加 Bing Webmaster Tools 站点验证标签：
  - `<meta name="msvalidate.01" content="EA1D7C1A527755CFEACE1520F36EC05F" />`
- `frontend-user-v3-www/src/data/seoLandingPages.js` 新增 `buildSeoLandingStructuredData()`，每个 SEO 单页按同一份配置生成 JSON-LD：
  - `Organization`
  - `WebSite`
  - `WebPage`
  - `BreadcrumbList`
- `frontend-user-v3-www/src/utils/pageMeta.js` 增加运行时结构化数据同步，SPA 路由切换到 SEO 单页时会写入 `script#route-structured-data`。
- `frontend-user-v3-www/scripts/prerender-www.mjs` 增加静态 HTML 结构化数据注入，确保搜索引擎直接抓取 `dist/<path>/index.html` 时也能读取 JSON-LD。
- `frontend-user-v3-www/tests/seoLandingPages.test.mjs` 增加结构化数据生成断言，避免后续扩展 SEO 页时漏掉必要 JSON-LD。

本轮参考的官方方向：

- Google Search Central 建议描述摘要准确概括页面内容，避免所有页面复用同一段描述。
- Google Search Central 支持并推荐用 JSON-LD 提供结构化数据，且结构化数据应与页面可见内容一致。
- sitemap 与 canonical 继续由构建脚本统一生成，避免路由、预渲染和站点地图数据分叉。
