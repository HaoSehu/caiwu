## 一、当前生产拓扑

项目跑在单台宝塔服务器上，结构如下：

```
宝塔站点 (Nginx)
  ├── 官网/用户入口 -> frontend-user-v3-www/dist 静态资源
  ├── 用户控制台   -> frontend-user-v4-console/dist 静态资源
  ├── 管理端站点   -> frontend-admin-v3/dist 静态资源
  └── 后端 API 站点 -> backend/public (PHP-FPM)
                       │
                       ├── MySQL 8      (本机或独立实例)
                       ├── Redis        (缓存)
                       └── 宝塔计划任务   每分钟执行一次 schedule:run
```

生产环境特征：

- **前后端各自独立宝塔站点**，Nginx 只做静态托管 + API 反代
- **后端入口走 PHP-FPM**，不使用 `php artisan serve` 或 `app:serve`
- **没有常驻 Queue Worker**，队列消费被并入 `schedule:run`
- **计划任务与队列消费合一**：每分钟一次 `schedule:run`，因此异步任务最坏延迟 60 秒左右

## 二、计划任务配置

### 2.1 宝塔计划任务

在宝塔面板 → 计划任务 → 添加：

- 任务类型：Shell 脚本
- 执行周期：每分钟执行
- 脚本内容：

```bash
cd /你的项目/backend
php artisan schedule:run >> /dev/null 2>&1
```

说明：

- 这条计划会同时驱动：`系统自动化任务`、`支付后的开通队列`、`推荐返佣异步任务`、`发送短信/邮件`、`生成续费账单`、`服务到期检查` 等
- 不要额外手动 `queue:work`，避免重复消费

### 2.2 后端调度内容

当前调度能力以真实命令与路由注册为准。查看真实启用清单请看：

- `backend/routes/console.php`
- `backend/app/Console/Commands/`
- 管理端 "调度总览"：`GET /api/admin/schedules/overview`

典型任务（以代码为准）：

- 自动续费检查
- 账单逾期处理
- 服务到期停用与终止
- 上游状态同步
- 各类日志清理

## 三、部署流程

### 3.1 后端部署

```bash
# 项目根下切到 backend
cd backend

# 拉代码（宝塔一般自带 Git 钩子或手动 git pull）
git pull

# 安装依赖
composer install --no-dev --optimize-autoloader

# 迁移
php artisan migrate --force

# 清旧缓存
php artisan config:clear
php artisan route:clear
php artisan cache:clear

# 生产缓存
php artisan config:cache
php artisan route:cache
```

### 3.2 前端部署

```bash
# 官网/用户入口
cd frontend-user-v3-www
npm install
npm run build
# 输出 frontend-user-v3-www/dist，按宝塔站点根配置指向

# 管理端
cd frontend-admin-v3
npm install
npm run build
# 输出 frontend-admin-v3/dist，按宝塔站点根配置指向

# 用户控制台
cd frontend-user-v4-console
npm install
npm run build
# 输出 frontend-user-v4-console/dist，按宝塔站点根配置指向
```

### 3.3 .env 关键项

最小化需要核对的 `.env`：

- `APP_ENV=production`
- `APP_DEBUG=false`
- `APP_URL=https://你的后端域名`
- `FRONTEND_URL=https://你的官网/用户入口域名`（`/media/*` 与兼容期 `/uploads/*` 上传资源的公网基础 URL 走这里）
- `DB_*`：MySQL 8 连接
- `REDIS_*`：Redis 连接
- `CACHE_STORE=redis`
- `SESSION_DRIVER=file`（当前生产；目标是改成 `redis`）
- `QUEUE_CONNECTION=database`（当前生产；目标是改成 `redis`）
- `SANCTUM_STATEFUL_DOMAINS=你的前端域名`

整改项（暂未上线）：`SESSION_DRIVER` 与 `QUEUE_CONNECTION` 迁到 Redis。当前没有单独整改专题文档时，以 `文档/开发文档/架构/架构现状说明.md` 和实际配置为准。

## 四、本地启动差异

和生产不同，本地用一条封装命令同时拉起多进程：

```bash
cd backend
php artisan app:serve
# 等价于：HTTP + VNC Relay + queue:work --queue=referral,provision,default

# 如果本地想同时拉起调度
php artisan app:serve --with-schedule
```

细节见 `启动指南.md` 与 `backend/app/Console/Commands/ServeBackendStackCommand.php`。

## 五、常见运维操作

### 5.1 查看调度运行情况

- 宝塔计划任务页可看脚本日志
- `backend/storage/logs/laravel.log`
- 管理端 `/api/admin/schedules/overview` 与 `/api/admin/logs/tasks`

### 5.2 手动触发一次调度

```bash
cd backend
php artisan schedule:run
```

### 5.3 手动跑一次队列消费

正常不需要。只在排查"队列已堆积但未消费"时用：

```bash
cd backend
php artisan queue:work --once
```

### 5.4 清理失败队列

```bash
cd backend
php artisan queue:retry all     # 重试全部失败
php artisan queue:flush         # 清空失败队列（慎用）
```

### 5.5 OPcache / 路由 / 配置缓存刷新

上线后如果路由或配置没生效，依次跑：

```bash
cd backend
php artisan route:clear && php artisan config:clear && php artisan cache:clear
php artisan route:cache && php artisan config:cache
# 重启 PHP-FPM（宝塔面板 → PHP → 重启）
```

### 5.6 PHP 禁用函数问题

Composer 报 `Call to undefined function putenv()` 等错误时，优先核对宝塔 PHP 的禁用函数和 CLI / FPM 配置差异；当前仓库未保留单独修复指南。

## 七、回滚策略

- 后端：代码回退 + `composer install` + `php artisan migrate:rollback`（仅当迁移可逆）
- 前端：按站点独立回滚，直接恢复旧 `dist`
- 数据库：禁止在生产直接 `migrate:rollback` 不可逆迁移，走备份还原
- 关键业务（支付、开通、返佣）回退前必须先冻结 `schedule:run`，避免边回滚边产生新异步动作
