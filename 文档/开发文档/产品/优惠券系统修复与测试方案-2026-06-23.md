# 优惠券系统修复与测试方案

> 本文档整合优惠券/活动券全链路审查后的修复方案与测试方案，作为后续实施的唯一依据。

## 文档信息

- **创建日期**: 2026-06-23
- **审查范围**: `coupons` / `user_coupons` / `invoices.coupon_id` / `OrderService` / `PaymentService` / `CouponService` / `CouponCampaignService` / 前端三端优惠券入口
- **审查发现**: 4 个 P0 数据正确性问题、4 个 P1 健壮性问题、4 个 P2 设计问题
- **受众**: 项目经理、后端工程师、前端工程师、QA

## 第一部分：修复方案

### 一、修复目标

针对审查发现的 4 个 P0 数据正确性问题 + 4 个 P1 健壮性问题 + 4 个 P2 设计问题，分三阶段实施，**最小变动、向后兼容、可灰度**。

### 二、方案默认假设

> 若以下假设与业务预期不符，请在实施前提出。

| # | 默认决策 | 理由 |
|---|---------|------|
| Q1 | 退款**返还**使用配额 | 用户友好，与电商常态一致 |
| Q2 | `first_order_only` **退款不返还**（核销即占用） | "首单"是身份判定，不是次数 |
| Q3 | 选用**预占字段** `reserved_until` | 比锁行更可控、自动过期 |
| Q4 | 异步用**队列 job** 替代 `app()->terminating()` | 持久化、可重试 |

#### Step 1.5 重写核销逻辑

**文件**：`backend/app/Services/Finance/CouponService.php` — `syncInvoiceCouponUsage`

```php
public function syncInvoiceCouponUsage(Invoice $invoice): void
{
    $couponId = (int) ($invoice->coupon_id ?? 0);
    $userCouponId = (int) ($invoice->user_coupon_id ?? 0);
    if ($couponId <= 0 && $userCouponId <= 0) return;

    DB::transaction(function () use ($couponId, $userCouponId, $invoice) {
        // 1. 统计 coupon.used_count，(保持不变)
        if ($couponId > 0) {
            $coupon = Coupon::query()->whereKey($couponId)->lockForUpdate()->first();
            if ($coupon instanceof Coupon) {
                $coupon->forceFill(['used_count' => $this->countCouponUsedInvoices($couponId)])->save();
            }
        }

        // 2. user_coupon 状态机
        if ($userCouponId > 0 && $this->hasUserCouponsTable()) {
            $uc = UserCoupon::query()->whereKey($userCouponId)->lockForUpdate()->first();
            if (! $uc instanceof UserCoupon) return;

            $hasActivePaidInvoice = Invoice::query()
                ->where('user_coupon_id', $userCouponId)
                ->whereIn('status', self::USED_INVOICE_STATUSES)
                ->exists();

            if ($hasActivePaidInvoice) {
                // 已核销
                $uc->forceFill([
                    'status'       => UserCouponStatus::USED,
                    'used_at'      => $uc->used_at ?: $this->resolveUserCouponLastUsedAt($userCouponId),
                    'last_used_at' => $this->resolveUserCouponLastUsedAt($userCouponId),
                    'reserved_until' => null,
                ])->save();
            } else {
                // 全部退款/取消 → 回滚到可用 (按 Q1 默认)
                $uc->forceFill([
                    'status'    => UserCouponStatus::OWNED,
                    'used_at'   => null,
                    'last_used_at' => null,
                    'reserved_until' => null,
                ])->save();
            }
        }
    });
}
```

#### Step 1.7 预占字段（按 Q3 默认）

**文件**：`CouponService.php` — `reserveOwnedCouponForInvoice`

```php
public function reserveOwnedCouponForInvoice(...): ?array
{
    // ...现有查找...
    $userCoupon = UserCoupon::query()
        ->with('coupon')
        ->where('user_id', $userId)
        ->whereHas('coupon')
        ->where('status', UserCouponStatus::OWNED)
        ->where(function ($q) {
            $q->whereNull('reserved_until')->orWhere('reserved_until', '<', now());
        })
        ->lockForUpdate()
        ->find($resolvedUserCouponId);

    throw_if(! $userCoupon, new BusinessException('优惠券不存在或已失效'));

    // 预占 10 分钟（与 quote_token 同步）
    $userCoupon->forceFill(['reserved_until' => now()->addMinutes(10)])->save();

    return $this->buildOwnedCouponPayload($userCoupon, $product, $billingCycle, $amount, $userId, $orderType);
}
```

**释放点**：
- 支付成功 → `syncInvoiceCouponUsage` 把 `reserved_until` 一并清 null
- 订单取消 → `releaseInvoiceCoupon` 同样清 null
- 10 分钟超时 → 自动失效（下次查询不命中）
