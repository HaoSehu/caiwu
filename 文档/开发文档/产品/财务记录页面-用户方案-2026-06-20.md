# 财务记录页面 — 产品方案

> 本文档写给人类阅读，不含技术术语。

## 背景

用户在控制台里管理自己的云服务时，需要查看自己的账单、订单和充值记录。目前控制台有账单和充值记录页面，但界面体验不够好，而且**完全没有订单记录页面**。用户无法方便地查看自己的订单历史，也不清楚订单和账单之间的关系。

## 目标

让用户在控制台里能方便地查看和管理自己的财务记录：
- 查看所有账单，了解每笔账单的详情
- 查看所有订单，了解订单状态和关联的账单
- 查看充值记录，了解账户资金变动
- 对未支付的订单/账单进行取消操作
- 快速跳转到支付页面完成付款

## 方案概述

我们采用**增强现有页面 + 新增订单模块**的方式：
1. 优化现有的账单记录和充值记录页面，让界面更清晰、功能更完善
2. 新增订单记录页面，让用户能查看所有订单
3. 为每个记录类型增加独立的详情页，展示完整信息

这样既能快速交付，又不影响现有的支付流程。

## 业务规则说明

### 订单和账单的关系
- 一个订单对应一个账单（1:1关系）
- 订单是购买行为的记录，账单是付款凭证
- 用户在订单详情页可以看到关联的账单信息，也可以跳转到账单详情

### 取消订单时会发生什么
取消未支付的订单后，系统会自动处理以下事项：
1. **关联账单也会被取消** — 不用担心账单还能继续支付
2. **优惠券会退回** — 如果订单使用了优惠券，取消后优惠券可以再次使用
3. **库存会释放** — 如果是新产品购买订单，取消后库存会恢复（续费订单不影响库存）
4. **待处理的支付会关闭** — 如果有正在进行的支付（比如支付宝扫码中），会自动关闭

### 订单状态说明
| 状态 | 含义 | 用户能做什么 |
|------|------|-------------|
| 待付款 | 订单已创建，等待支付 | 支付、取消 |
| 已付款 | 支付成功，等待系统处理 | 仅查看 |
| 开通中 | 系统正在开通服务 | 仅查看 |
| 已完成 | 服务已开通 | 仅查看 |
| 已取消 | 订单已取消（不可恢复） | 仅查看 |
| 已退款 | 订单已退款 | 仅查看 |

### 充值记录和账单的关系
- 充值记录（第三方支付，如支付宝）会关联一个充值类型的账单
- 余额支付、管理员手动开服、免费订单不会产生充值记录
- 在充值详情页可以看到关联的账单信息

## 功能说明

| 编号 | 功能点 | 说明 | 谁用 |
|------|--------|------|------|
| F1 | 账单记录列表 | 查看所有账单，支持按状态、类型筛选，搜索账单号，顶部显示待付金额等指标 | 用户 |
| F2 | 账单详情页 | 查看账单完整信息：金额、状态、关联订单、服务、优惠券、支付记录 | 用户 |
| F3 | 订单记录列表 | 查看所有订单（新购、续费、附加配置），支持筛选和搜索，顶部显示待付金额等指标 | 用户 |
| F4 | 订单详情页 | 查看订单完整信息：订单号、类型、状态、金额、关联账单、服务、优惠券 | 用户 |
| F5 | 充值记录列表 | 查看所有充值记录，支持按状态、渠道筛选，顶部显示充值金额等指标 | 用户 |
| F6 | 充值详情页 | 查看充值详情：支付金额、渠道、状态、交易号、到账时间、关联账单 | 用户 |
| F7 | 取消订单 | 对未支付的订单进行取消操作（需二次确认，确认弹窗会告知影响） | 用户 |
| F8 | 取消账单 | 对未支付的账单进行取消操作（需二次确认，确认弹窗会告知影响） | 用户 |
| F9 | 跳转支付 | 从订单详情或账单详情跳转到支付页面 | 用户 |
| F10 | 快捷筛选 | 列表页提供"最近7天""本月""待支付"等快捷筛选标签 | 用户 |

## 用户操作流程

### 查看账单记录
1. 用户进入控制台，点击左侧菜单"财务 → 账单记录"
2. 看到账单列表，顶部显示指标卡片（待付金额、本月账单数、总账单数）
3. 可以按状态、类型筛选，或搜索账单号；也可以点击快捷筛选标签（如"待支付""本月"）
4. 点击某条账单，进入账单详情页
5. 在详情页可以看到账单的完整信息，包括关联的订单、服务、优惠券和支付记录
6. 如果账单未支付，可以点击"去支付"按钮跳转到支付页面，或点击"取消账单"取消

### 查看订单记录
1. 用户进入控制台，点击左侧菜单"财务 → 订单记录"
2. 看到订单列表，顶部显示指标卡片（待支付订单数、待支付总金额、本月订单总金额）
3. 可以按状态、类型筛选，或搜索订单号；也可以点击快捷筛选标签
4. 点击某条订单，进入订单详情页
5. 在详情页可以看到订单的完整信息，包括关联的账单和服务
6. 如果订单未支付，可以点击"取消订单"按钮取消（弹窗会告知影响），或点击"去支付"跳转支付

### 取消订单
1. 用户在订单详情页点击"取消订单"按钮
2. 弹出确认弹窗，告知用户取消后的影响：
   - "取消后，关联的账单也将被取消，不可恢复"
   - "使用的优惠券将退回账户"
   - "如果是新产品购买，库存将释放"
3. 用户点击"确认取消"后，订单和关联账单状态变为"已取消"
4. 页面自动刷新，显示成功提示

### 取消账单
1. 用户在账单详情页点击"取消账单"按钮
2. 弹出确认弹窗，告知用户取消后的影响：
   - "取消后不可恢复"
   - "使用的优惠券将退回账户"
   - "如果是新产品购买，库存将释放"
3. 用户点击"确认取消"后，账单状态变为"已取消"
4. 页面自动刷新，显示成功提示

### 查看充值记录
1. 用户进入控制台，点击左侧菜单"财务 → 充值记录"
2. 看到充值记录列表，顶部显示指标卡片（本月充值金额、总充值金额）
3. 可以按状态、渠道筛选
4. 点击某条记录，进入详情页查看完整信息，包括关联的充值账单

### 支付流程衔接
1. 用户在订单详情页或账单详情页点击"去支付"
2. 跳转到账单支付页面（/client/invoices/:id/pay）
3. 支付成功后，显示成功提示，提供"查看订单"和"返回列表"两个入口
4. 支付失败时，显示失败提示，提供"重新支付"入口
5. 支付过程中遇到问题，页面底部提供"遇到问题？联系客服"入口

## 页面/交互变化

- **账单记录页面**：增加顶部指标卡片（待付金额、本月账单数、总账单数），增加快捷筛选标签，点击跳转独立详情页（非抽屉）
- **新增订单记录页面**：全新页面，展示订单列表，顶部指标卡片，支持筛选、搜索、快捷筛选、取消、跳转支付
- **新增订单详情页**：展示订单完整信息，含概览指标、基础信息、关联信息标签页，支持取消和跳转支付
- **充值记录页面**：增加顶部指标卡片（本月充值、总充值），点击跳转独立详情页（非抽屉）
- **新增账单详情页**：独立页面展示账单完整信息（当前是抽屉展示），含关联订单、服务、优惠券、支付记录
- **新增充值详情页**：独立页面展示充值完整信息（当前是抽屉展示），含关联账单

## 默认筛选条件

| 页面 | 默认筛选 | 说明 |
|------|---------|------|
| 账单记录 | 全部状态 | 用户能看到完整历史 |
| 订单记录 | 全部状态 | 用户能看到完整历史 |
| 充值记录 | 全部状态 | 用户能看到完整历史 |

## 影响范围

- **对用户**：新增订单记录查看能力，账单和充值记录体验提升，取消操作有更清晰的提示
- **对管理员**：无影响
- **对现有功能**：保持现有支付流程不变，账单详情页重构不影响支付功能

## 不做的事（范围外）

- 不做订单退款功能（退款需管理员操作）
- 不做批量操作（批量取消、批量支付）
- 不做账单导出功能
- 不做充值功能优化（充值页面保持现有设计）
- 不做移动端专项适配（保持现有响应式）
- 不做搜索历史保存（筛选条件不持久化）
