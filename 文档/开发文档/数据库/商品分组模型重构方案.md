# 商品分组模型 & 表结构重构方案

> **目标**：将自引用单表 + 4模型继承链，重构为3张独立物理表 + 3个独立 Model。
> **交付至**：另一个 AI 执行。

---

## 一、当前状态（起始点）

### 数据库（已就绪，无需改动）

3 张物理表 + `products` 表，FK 链完整：

```sql
-- ============================================
-- 1. first_product_groups (一级分类，7条)
-- ============================================
CREATE TABLE `first_product_groups` (
  `id`              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
```

### 代码现状（需要改动）

4个模型继承链 —— **`ProductGroup` 基类已被删除**：

| 模型 | `$table` | 问题 |
|---|---|---|
| `FirstProductGroup` extends `ProductGroup` | `product_groups` | ❌ 表不存在，extends 不存在的类 |
| `SecondProductGroup` extends `ProductGroup` | `second_product_groups` | ❌ extends 不存在的类 |
| `ThirdProductGroup` extends `ProductGroup` | `third_product_groups` | ❌ extends 不存在的类 |

**核心问题**：
1. 三个子类都 `extends ProductGroup`，但 `ProductGroup.php` 已被删除 → 当前代码会报 Fatal Error
2. `FirstProductGroup::$table = 'product_groups'` → 表不存在（应该用 `first_product_groups`）
3. 每个子类都有大量冗余代码：`hasLevelColumn()`、全局 Scope、`accessor` 映射 `parent_id`

**涉及文件数**：~31 个 app 文件 + ~16 个 test 文件

### Step 1: 修复 FirstProductGroup 模型

**文件**：`backend/app/Models/FirstProductGroup.php`

**改动**：
- 不再 `extends ProductGroup`，改为 `extends Model`
- `$table = 'first_product_groups'`
- 删除 `hasLevelColumn()`、全局 Scope、`booted()`
- 删除 `products()` 和 `secondProductGroups()` 中的兼容逻辑
- `$fillable` 精简为表中的实际字段

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class FirstProductGroup extends Model
{
    protected $table = 'first_product_groups';

    protected $fillable = [
        'code',
        'product_type',
        'name',
        'slug',
        'description',
        'icon',
        'banner_image',
        'sort_order',
        'is_visible',
        'is_system',
        'legacy_product_type',
    ];

    protected function casts(): array
    {
        return [
            'sort_order' => 'integer',
            'is_visible' => 'integer',
            'is_system' => 'integer',
        ];
    }

    public function secondProductGroups(): HasMany
    {
        return $this->hasMany(SecondProductGroup::class, 'first_product_group_id');
    }

    public function products(): HasMany
    {
        return $this->hasMany(Product::class, 'product_group_id');
    }
}
```

**关键**：不再需要 `hasLevelColumn()`，不再需要 `booted()`，不再需要全局 Scope。

### Step 4: 修复 Product 模型

**文件**：`backend/app/Models/Product.php`

**改动**：
1. 删除 `use App\Models\ProductGroup;`（类已删除）
2. 删除 `firstProductGroup()`、`secondProductGroup()`、`thirdProductGroup()` — 原来4个关系删掉3个
3. 修改 `productGroup()` 指向 `ThirdProductGroup`
4. 简化 `resolvedProductGroupHierarchy()` 和 accessor 方法（去掉 `ProductGroup` 引用）
5. `$fillable` 中删掉 `first_product_group_id`, `second_product_group_id`, `third_product_group_id`（表中已无这些列）
6. `$casts` 中删掉对应的 cast
7. 修改 `inProductGroupTree()` scope（不再需要自引用递归）
8. 修改 `withVisibleProductGroupPath()` / `underRootProductGroup()` scope（改为 JOIN 三级表）
9. 修改 `rootProductGroupSubquery()`（不再需要 LEFT JOIN + CASE）

**关键方法修改**：

```php
// 关系 - 只保留1个
public function productGroup(): BelongsTo
{
    return $this->belongsTo(ThirdProductGroup::class, 'product_group_id');
}

// 辅助访问器 - 通过 productGroup->secondProductGroup 递归取上级
public function getFirstProductGroupIdAttribute(): ?int
{
    return $this->productGroup?->secondProductGroup?->first_product_group_id
        ? (int) $this->productGroup->secondProductGroup->first_product_group_id
        : null;
}

public function getSecondProductGroupIdAttribute(): ?int
{
    return $this->productGroup?->second_product_group_id
        ? (int) $this->productGroup->second_product_group_id
        : null;
}

public function resolvedProductGroupHierarchy(): array
{
    $third = $this->relationLoaded('productGroup') ? $this->productGroup : null;
    $second = $third?->relationLoaded('secondProductGroup') ? $third->secondProductGroup : null;
    $first = $second?->relationLoaded('firstProductGroup') ? $second->firstProductGroup : null;
    return [$first, $second, $third];
}
```

**scope 修改**：

```php
// inProductGroupTree - 简化，商品直接通过 product_group_id 查询即可
// 如果是查三级分组下的商品，直接 where product_group_id = $groupId
// 如果是查二级分组下的商品，JOIN third_product_groups WHERE second_product_group_id = $groupId
// 如果是查一级分组下的商品，JOIN third → second WHERE first_product_group_id = $groupId
public function scopeInProductGroupTree(Builder $query, int $groupId): Builder
{
    // 假设只支持查三级分组下的商品（业务上95%是这种场景）
    return $query->where('product_group_id', $groupId);
}
```

### Step 6: 更新 ProductGroupHierarchyFields

**文件**：`backend/app/Support/ProductGroupHierarchyFields.php`

**改动**：
- 删除 `use App\Models\ProductGroup;`
- 所有 `instanceof ProductGroup` 改为 `instanceof FirstProductGroup` 或 `instanceof ThirdProductGroup`
- 简化 `fromProduct()`——直接用关系链取值，不再需要复杂的 self-referencing 计算
- `firstGroupByCode` 直接查 `FirstProductGroup::query()->where('code', $code)`
- 删除 `secondGroupByLegacyId` / `thirdGroupByLegacyId`（新表不需要 legacy ID 映射）
- 保留 `fromProduct()` 的核心字段输出格式不变

```php
// fromProduct 简化后的核心逻辑
public static function fromProduct(Product $product): array
{
    $third = $product->relationLoaded('productGroup') ? $product->productGroup : null;
    $second = $third?->relationLoaded('secondProductGroup') ? $third->secondProductGroup : null;
    $first = $second?->relationLoaded('firstProductGroup') ? $second->firstProductGroup : null;

    $firstId = $first ? (int) $first->id : null;
    $firstCode = trim((string) ($first?->code ?? ''));
    $firstName = trim((string) ($first?->name ?? ProductType::labelOf($firstCode)));
    $secondId = $second ? (int) $second->id : null;
    $secondName = trim((string) ($second?->name ?? ''));
    $thirdId = $third ? (int) $third->id : null;
    $thirdName = $third ? trim((string) ($third?->name ?? '')) : null;

    $fallbackType = trim((string) ($product->getRawOriginal('product_type') ?: ''));
    $productType = ProductType::businessValueForFirstGroup($first, $fallbackType);

    return [
        'first_product_group_id' => $firstId,
        'first_product_group_code' => $firstCode,
        'first_product_group_name' => $firstName,
        'second_product_group_id' => $secondId,
        'second_product_group_name' => $secondName,
        'second_product_group_parent_id' => $firstId,
        'second_product_group_parent_name' => $firstName,
        'third_product_group_id' => $thirdId,
        'third_product_group_name' => $thirdName,
        'effective_product_group_id' => $thirdId ?? $secondId,
        'effective_product_group_level' => $thirdId !== null ? 3 : ($secondId !== null ? 2 : null),
        'product_type' => $productType,
        'product_type_label' => ProductType::businessLabelOf($productType),
        'service_type_code' => $productType,
    ];
}
```

### 特别注意

1. **`ProductGroup.php` 已被删除**→三个子类的 `extends ProductGroup` 会导致 Fatal Error，必须作为第一步修复
2. **`FirstProductGroup::$table = 'product_groups'`** 必须改为 `'first_product_groups'`
3. **`ProductGroupHierarchyFields` 的 `fromProduct()`** 用到了 `$product->resolvedProductGroupHierarchy()` 以及 `instanceof ProductGroup`，全部要改为通过 `productGroup → secondProductGroup → firstProductGroup` 关系链取值
4. **`ProductGroupV2QueryService`** 中有大量 `->select('product_groups.*')` 硬编码，需要改为正确的表名
5. **前端 API 响应格式不能变**——所有 Resource 的字段名和结构保持不变
