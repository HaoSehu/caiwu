## 1. 外键审计命令

新增命令：

```bash
cd backend
php artisan db:audit-foreign-keys --strict
```

命令输出所有 `*_id` 字段的三类结果：

| 分类 | 含义 |
| --- | --- |
| `existing_fk` | 已有数据库级外键 |
| `candidate_fk` | 可补数据库级外键，命令同时输出 orphan 计数 |
| `polymorphic_or_snapshot` | 多态、外部平台 ID、批次号、链路追踪号或历史快照，不应补 FK |

## 3. 本次新增约束

本次新增 35 个数据库级外键，覆盖以下业务域：

- 账号权限：`admin_user_roles`、`admin_users`、`users.member_level_id`、`users.referrer_user_id`
- 内容通知：`content_articles.category_id`、`notice_reads.*`
- 优惠券：`coupon_campaigns.last_coupon_id`、`coupons.coupon_campaign_id`、`user_coupons.user_id`
- 交易账单：`orders.*`、`payments.order_id`、`invoices.service_id`、`invoices.coupon_id`
- 返佣：`referral_account_logs.user_id`、`referral_rewards.*`、`referral_withdrawals.user_id`
- 工单：`tickets.service_id`、`tickets.assignee_id`、`ticket_replies.quote_reply_id`
- 会话和用户通知：`sessions.user_id`、`user_notifications.user_id`
- 实名历史：`verification_histories.user_id`

所有约束的 `ON UPDATE` 均为 `NO ACTION`。`ON DELETE` 按业务语义分别采用：

| 删除规则 | 使用场景 |
| --- | --- |
| `RESTRICT` | 财务、交易、返佣、实名等必须保留归属的审计数据 |
| `SET NULL` | 日志、订单、账单、工单等需要保留历史但允许引用对象清理的字段 |
| `CASCADE` | 纯从属关系，如阅读记录、会话、站内通知 |
