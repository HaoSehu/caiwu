# 工作区防复脏规则

- 文档性质：现行规则
- 生效日期：`2026-06-23`
- 适用范围：Caiwu 仓库根目录、后端、三个前端、共享层、文档树和 Agent 配置

## 1. 核心目标

工作区允许存在一个当前任务的未提交改动，但不允许生成物、临时报告、旧前端目录、数据库 dump、测试 SQLite 和本机工具反复进入 Git 状态。

## 2. 固定检查命令

每次切换任务、提交清洁批次或合并前执行：

```bash
npm run workspace:health
```

该命令调用 `backend/scripts/workspace_health_check.mjs`，只检查不删除。失败时先处理报告中的路径，再继续开发或提交。

## 3. 硬性禁止

- 禁止追踪 `backend/storage/framework/testing/*.sqlite`。
- 禁止追踪 `dist/`、`node_modules/`、日志、zip、根目录 SQL dump。
- 禁止在仓库根目录新增临时 Markdown、审查报告、交接报告或演示文档。
- 禁止在 `frontend-admin-v3`、`frontend-user-v3-www`、`frontend-user-v4-console` 根部放审查报告或优化报告。
- 禁止重新引入旧前端目录作为现行路径：`frontend-admin`、`frontend-client`、`frontend-user-v3-console`、`frontend-www-v2`、`frontend-console-v2`。

## 4. 允许保留

- 根目录规则文档：`AGENTS.md`、`CLAUDE.md`、`开发规范.md`、`启动指南.md`、`页面风格.md`。
- 前端包自带说明：`README.md`、`README-zh_CN.md`、`CHANGELOG.md`、`PUBLISH.md`。
- 本地工具索引目录可被 `.gitignore` 忽略，但不应作为提交内容。

## 5. 文档归位

- 长期规则进入 `文档/开发文档/治理/`。
- 治理执行记录进入 `文档/开发记录/治理/`。
- 审查和优化报告进入 `文档/审查/`。

## 6. Agent 配置边界

- `AGENTS.md` 是仓库规则真源。
- `.codex/skills` 是 Codex 项目技能入口。
- `.github/agents`、`.github/skills` 和 `.github/copilot-instructions.md` 面向 GitHub/Copilot。
- `.agents/skills` 是通用 Agent 技能库镜像或工作副本；规则变更应先确认真源，再同步。

同一条项目规则不得在多个位置独立改写。确需多端同步时，先改真源，再做同步检查。
