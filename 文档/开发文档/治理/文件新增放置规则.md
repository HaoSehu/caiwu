# 文件新增放置规则

- 文档性质：现行规则
- 执行日期：2026-05-23
- 最后更新：`2026-07-02`（文档树仅保留长期开发文档）
- 读者画像：所有开发人员、运维人员

## 1. 目的

防止治理后的目录结构再次失控。新增文件前先查本表，确认放置位置。

## 2. 文档保留标准

| 类型 | 判断标准 | 处理方式 |
|------|----------|----------|
| 长期开发文档 | 修改后需要长期维护的固定规范、指南、规则、接口说明 | 进入 `开发文档/` |
| 一次性产物 | 报告、快照、交接、审计、日志、临时计划 | 不进入长期文档树；必要信息提炼后并入现有真源 |

## 3. 放置规则

### 3.1 开发文档（永久规则、长期维护）

| 文件类型 | 放置位置 | 说明 |
|----------|----------|------|
| 架构文档 | `开发文档/架构/` | 技术架构现状、方案设计 |
| 后端规范 | `开发文档/后端/` | 后端规则、接口、目录规范 |
| 前端规范 | `开发文档/前端/` | 前端规则、结构、实现规范 |
| 数据库流程 | `开发文档/数据库/` | 数据库结构说明、迁移流程 |
| 上游文档 | `开发文档/集成/` | 第三方 API 文档、对接说明 |
| 治理规则 | `开发文档/治理/` | 目录治理、文件放置规则 |
| 部署运维 | `开发文档/` | 根目录，除非形成稳定子目录 |

### 3.2 一次性产物

以下内容不进入长期文档树：

- 审查/审计报告
- 任务交接
- 测试执行报告和原始输出
- 数据库快照、迁移日志、临时审计
- 治理执行记录、覆盖矩阵、阶段清单
- 构建日志、开发日志
- HTML 原型、临时演示页和截图材料

若一次性产物包含后续仍需遵守的规则，只提炼规则本身并更新 `开发文档/` 中对应真源。

后端维护脚本放 `backend/scripts/`，不放长期业务代码。

## 4. 禁止事项

- 禁止在仓库根目录新建文档或演示文件
- 禁止在 `backend/` 或前端目录根部新建日志、报告、快照文件
- 可再生产物（`dist/`、`.phpunit.cache/`、`node_modules/`）不纳入版本管理

## 5. 命名规则

- 规则型文档（开发文档）：`主题 + 类型.md`
- 现行规范直接原位更新，不新增 `v2`、`最新版`、`最终版` 后缀
