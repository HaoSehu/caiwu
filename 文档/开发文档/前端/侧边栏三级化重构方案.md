# 管理端侧边栏菜单三级化重构方案

## 一、数据结构变更

### 现状（二级结构）

`frontend-admin-v3/src/store/modules/permission.ts` 中 `ADMIN_MENU_GROUPS` 采用 `MenuGroupConfig` 类型，本质是一层分组→一层叶子：

```typescript
interface MenuGroupConfig {
  path: string;       // 分组虚拟路径，如 /admin/menu/analytics
  title: LocalizedTitle;
  icon: ReturnType<typeof shallowRef>;
  orderNo: number;
  children: MenuChild[];  // 直接挂叶子页面路径或 MenuChildConfig
}
```

### 目标（三级结构）

新增 `MenuSubGroupConfig`，`MenuGroupConfig.children` 从 `MenuChild[]` 改为 `MenuSubGroupConfig[]`：

```typescript
interface MenuSubGroupConfig {
  title: LocalizedTitle;     // L2 二级名称，如"订单管理"
  orderNo: number;           // L2 二级排序
  children: MenuChild[];     // L3 三级叶子页面
}
```

### 改动文件清单

| 文件 | 改动 |
|------|------|
| `src/store/modules/permission.ts` | 新增 `MenuSubGroupConfig` 类型；修改 `MenuGroupConfig.children` 类型；重写 `ADMIN_MENU_GROUPS`；修改 `buildMenuGroup` 递归生成 L2 子分组路由 |
| `src/layouts/` 相关侧边栏组件 | 适配 TDesign Menu 三级渲染（`t-submenu` 嵌套） |

## 四、旧分组解散对照

| 原分组 | 解散去向 |
|--------|---------|
| 经营分析 | → 数据看板 |
| 商品与供应 | → 产品配置（商品管理 + 上游供应） |
| 客户与身份 | → 用户管理 |
| 服务交付 | → 工单处理 |
| 交易账务 | → 财务管理（订单管理 + 账务管理） |
| 营销权益 | → 用户管理（会员权益）+ 营销推广（优惠券 + 推广管理） |
| 站点内容 | → 站点内容（站点配置 + 内容管理） |
| 通知与接口 | → 站点内容（通知与接口） |
| 集成通道 | → 系统设置（集成插件） |
| 自动化审计 | → 系统设置（自动化）+ 日志中心 |
| 组织权限 | → 系统设置（权限管理） |

## 五、实施步骤

1. **修改类型定义**：`permission.ts` 新增 `MenuSubGroupConfig` 接口
2. **重写菜单配置**：替换 `ADMIN_MENU_GROUPS` 为三级结构
3. **修改 `buildMenuGroup`**：递归处理 L2 子分组，生成嵌套 `RouteRecordRaw`
4. **适配侧边栏组件**：L2 子分组渲染为 TDesign `t-submenu` 嵌套在 L1 `t-submenu` 内
5. **验证**：`npm run build`（含 `vue-tsc --noEmit`）确认类型无误
6. **功能测试**：管理端登录后逐菜单展开确认三级展开/收起/高亮正常
