- 看接口能力：先看 `API清单导航.md`，再查 `后端API清单.md`
- 看接口格式：先看 `API格式规范.md`
- 看产品流程：先看 `产品总览.md`
- 看目录结构：先看 `架构现状说明.md` 和 `后端目录分类规范.md`

## 5. 不在这里保留什么

以下内容原则上不再在 `文档/` 目录长期保留：

- 历史蓝图
- 已过期的阶段性审查材料
- 一次性排障过程记录
- 与当前代码已经脱节的平行版本文档

需要回溯旧方案时，直接查 `git` 历史。
