## 执行总结

### 已完成优化

| 优化项 | 改动 | 效果 |
|---|---|---|
| TTL 优化 | 调整 8 个服务的缓存 TTL | 减少缓存失效频率，降低后端压力 |
| 前缀优化 | 移除 Redis 和 Cache 前缀 | 键名更简洁，便于调试 |
| Volatile Store | 新增 `redis_volatile` (DB 2) | 临时数据与业务缓存隔离 |
| 短 TTL 迁移 | 7 个服务的临时数据迁移 | 验证码、Token 等与业务缓存分离 |

### 缓存分层架构

```
Redis DB 0 (default)  - 队列、会话
Redis DB 1 (cache)    - 业务缓存（产品目录、设置、仪表盘）
Redis DB 2 (volatile) - 临时数据（验证码、Token、节流）
```

### TTL 优化详情

| 服务 | 改前 | 改后 | 说明 |
|---|---|---|---|
| HomeHeroService | 120s | 300s | 首页内容不频繁变化 |
| ContentArticleService | 120s/300s | 300s/600s | 文章列表/分类更稳定 |
| ServiceOverviewService | 60s | 120s | 服务概览 |
| ServiceDetailService | 15-60s | 30-120s | 服务详情/远程状态 |
| ClientFinanceQueryService | 30s | 120s | 余额统计 |
| DashboardService | 15s | 30s | 发票列表 |

### 迁移到 Volatile Store 的服务

1. **VerificationCodeService** - 验证码
2. **ServiceVncService** - VNC Token
3. **LoginRiskControlService** - 登录风控锁
4. **ProductSyncService** - 库存缓存/节流
5. **AuthService** - 管理员代登凭证
6. **CheckoutSecurityService** - 结算临时 Token
