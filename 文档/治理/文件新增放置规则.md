# 文件新增放置规则

- 文档性质：现行规则
- 执行日期：2026-05-23
- 读者画像：所有开发人员、运维人员

## 1. 目的

防止治理后的目录结构再次失控。新增文件前先查本表，确认放置位置。

## 2. 放置规则

| 文件类型 | 放置位置 | 说明 |
|----------|----------|------|
| 演示页/原型 | `文档/前端/原型与素材/` | HTML 原型、UI 演示 |
| 数据库快照 | `文档/数据库/快照归档/` | SQL dump、数据库结构快照 |
| 测试输出 | `文档/测试/原始输出/` | 测试运行日志和输出 |
| 测试报告 | `文档/测试/` | 带日期的测试结果归档 |
| 构建日志 | `文档/归档/历史资料/` | 历史构建记录 |
| 开发日志 | `文档/归档/历史资料/dev-logs/` | dev server 日志 |
| 上游文档 | `文档/集成/` | 第三方 API 文档、对接说明 |
| 治理报告 | `文档/治理/` | 目录治理、代码审查报告 |
| 产品文档 | `文档/产品/` | 产品全局视角 |
| 架构文档 | `文档/架构/` | 技术架构现状 |
| 后端规范 | `文档/后端/` | 后端规则、接口、目录规范 |
| 前端规范 | `文档/前端/` | 前端规则、结构、实现规范 |
| 部署运维 | `文档/` | 当前统一放文档根目录 |
| 后端维护脚本 | `backend/scripts/` | 不放长期业务代码 |

## 3. 禁止事项

- 禁止在仓库根目录新建文档或演示文件
- 禁止在 `backend/` 或前端目录根部新建日志、报告、快照文件
- 可再生产物（`dist/`、`.phpunit.cache/`、`node_modules/`）不纳入版本管理

## 4. 命名规则

- 规则型文档：`主题 + 类型.md`（如 `产品总览.md`）
- 带日期文档：快照、分析、报告、验收类文件名含日期（如 `数据库结构说明-idc-2026-04-17.md`）
- 现行规范直接原位更新，不新增 `v2`、`最新版`、`最终版` 后缀
