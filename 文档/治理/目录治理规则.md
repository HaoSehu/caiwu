# 目录治理规则

- 文档性质：现行规则
- 对齐时间：2026-05-23
- 读者画像：所有开发人员、运维人员

## 1. 资产分类标准

### 1.1 Core（核心资产）
- **定义**：源码、配置、正式测试、正式文档
- **位置**：保留原位
- **示例**：
  - `backend/app/` - Laravel 后端源码
  - `frontend-admin/src/` - 管理端前端源码
  - `frontend-client/src/` - 用户端前端源码
  - `shared/` - 共享代码
  - `文档/` - 正式文档

### 1.2 Generated（生成物）
- **定义**：构建产物、自动生成声明、缓存、日志
- **位置**：移动到归档或隔离区
- **示例**：
  - `frontend-admin/dist/` - 前端构建产物
  - `frontend-client/dist/` - 前端构建产物
  - `backend/.phpunit.cache/` - 测试缓存
  - `*.log` - 日志文件

### 1.3 Runtime（运行时产物）
- **定义**：运行时输出、测试输出、临时导出、上传样本
- **位置**：移入运行产物区
- **示例**：
  - `backend/storage/app/` - 运行时文件
  - `backend/storage/logs/` - 运行时日志
  - 测试输出文件

### 1.4 Archive（归档资产）
- **定义**：SQL 快照、阶段报告、演示页面、截图、旧方案材料
- **位置**：移入归档区
- **示例**：
  - `*.sql` / `*.sql.gz` - 数据库快照
  - `*-demo.html` - 演示页面
  - `*.png` / `*.jpg` - 截图素材
  - 阶段性报告文档

### 1.5 Unknown（待判定资产）
- **定义**：来源不明但可能有用的文件
- **位置**：先移入待判定区，后续再判断
- **示例**：
  - 用途不明确的脚本
  - 历史遗留文件

## 3. 文件移动规则

### 3.1 高置信度移动（立即执行）
1. **根目录演示文件** → `文档/前端/原型与素材/`
   - `coupon-demo.html`
   - `dashboard-demo.html`
   - `邮箱模板预览.html`

2. **根目录图片素材** → `文档/前端/原型与素材/`
   - `mobile-page.png`
   - `mobile-product-drawer.png`

3. **根目录 SQL 快照** → `文档/数据库/快照归档/`
   - `idc_2026-05-22_04-00-02_mysql_data.sql`
   - `idc_2026-05-22_04-00-02_mysql_data.sql.gz`

4. **后端测试输出** → `文档/测试/原始输出/`
   - `backend/test_results.txt`
   - `backend/test_output.txt`

5. **前端开发日志** → `文档/归档/历史资料/dev-logs/`
   - `frontend-admin/codex-dev.err.log`
   - `frontend-admin/codex-dev.out.log`
   - `frontend-client/codex-dev.err.log`
   - `frontend-client/codex-dev.out.log`

### 3.2 中置信度移动（标记后执行）
1. **构建产物**（本阶段不删除，标记为"建议删除"）
   - `frontend-admin/dist/`
   - `frontend-client/dist/`
   - `backend/.phpunit.cache/`

2. **临时文件**
   - `backend/storage/app/` 中的临时文件
   - `node_modules/` （可重新生成）

### 3.3 低置信度移动（待判定）
1. 用途不明确的脚本文件
2. 历史遗留的配置文件
3. 可能重复的文档

## 4. 禁止规则

### 4.1 根目录禁止项
- 演示页面（*.html）
- 截图素材（*.png, *.jpg）
- SQL 快照（*.sql, *.sql.gz）
- 测试输出文件
- 日志文件（*.log）
- 临时文件

### 4.2 目录命名规范
- 使用中文目录名（已建立的规范）
- 避免特殊字符
- 保持层级清晰

## 5. 新文件归档指南

### 5.1 开发过程中
- 新的演示页面 → `文档/前端/原型与素材/`
- 新的截图素材 → `文档/前端/原型与素材/`
- 数据库快照 → `文档/数据库/快照归档/`
- 测试输出 → `文档/测试/原始输出/`
- 开发日志 → `文档/归档/历史资料/dev-logs/`

### 5.2 阶段性工作
- 阶段报告 → `文档/归档/历史资料/`
- 迁移脚本 → `migration-output/`
- 备份文件 → `migration-output/preserve-backups-*/`

## 6. 执行流程

### 6.1 资产盘点
1. 扫描根目录散落文件
2. 分类标记（Core/Generated/Runtime/Archive/Unknown）
3. 生成移动映射表

### 6.2 目录准备
1. 创建目标目录（如不存在）
2. 验证目录结构

### 6.3 文件移动
1. 按映射表执行移动
2. 记录移动日志
3. 验证移动结果

### 6.4 报告输出
1. 生成整理结果报告
2. 生成建议删除清单
3. 更新治理文档

## 7. 风险控制

### 7.1 移动前检查
- 检查文件是否被占用
- 检查是否有硬依赖
- 备份重要文件

### 7.2 移动后验证
- 验证文件完整性
- 检查引用是否断裂
- 测试关键功能

### 7.3 回滚机制
- 保留移动日志
- 支持按日志回滚
- 定期创建快照

## 8. 维护机制

### 8.1 定期检查
- 每月检查根目录是否新增散落文件
- 每季度清理过期归档
- 每年评估目录结构合理性

### 8.2 文档更新
- 目录结构变化时更新本文档
- 新增文件类型时补充分类规则
- 执行治理后更新映射表
