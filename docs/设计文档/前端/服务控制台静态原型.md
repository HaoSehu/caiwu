# 服务控制台静态原型

- 状态：`needs-review`
- 更新：`2026-07-27`

本目录保留服务控制台重构前的可交互视觉原型，供产品与开发确认页面信息架构；它们不是 `frontend-user-v4-console` 的构建入口或运行时代码。

## 原型

- [服务器通用控制台](服务控制台原型/server-console.html)：实例状态、资源、连接、操作与监控。
- [NAT 控制台](服务控制台原型/nat-console.html)：公网地址、端口映射、连接信息与最近操作。

## 已确认边界

- 控制台只规划两张固定页面：`server`、`nat`；不采用按插件 schema 或动态组件拼装页面。
- 服务端决定服务有效页面并继续裁决实例归属、状态和上游能力；页面只展示被授权的操作。
- 原型中的 IP、服务编号、账号和资源值均为虚构展示数据，不代表真实服务或凭据。
