## 二、高严重度问题（10 项）

### H1. 标签页路由 keepAlive 全部设为 false

- **维度**：交互
- **位置**：`src/router/modules/admin/` 各路由配置
- **说明**：所有路由 `meta.keepAlive` 显式设为 `false`，而 `Content.vue` 默认值为 `true`。每次切 tab 都重新渲染组件、重新请求数据。
- **影响**：标签页间频繁切换时页面每次都重新加载，用户等待时间长。
- **建议**：对列表类页面启用 keepAlive，仅对详情/编辑页设为 false。

### H2. 所有列表页无可点击排序

- **维度**：交互
- **位置**：全局列表页（orders、invoices、users、services 等）
- **说明**：`t-table` 的 `columns` 中无 `sorter: true` 配置。用户无法按金额、时间等列排序。
- **影响**：高频场景（按时间排序、按金额排序）完全不可用。
- **建议**：至少为金额、时间、状态列增加 `sorter: true`。

### H3. 仪表盘/部分页面 catch 块静默失败

- **维度**：交互
- **位置**：`src/pages/dashboard/base/index.vue`、`src/pages/users/index.vue`
- **说明**：catch 块清空数据但无 `MessagePlugin.error` 调用。
- **影响**：仪表盘加载失败时用户看到空白图表无任何提示，误以为系统无数据。
- **建议**：所有 catch 块统一调用 `errorMessage()` 并展示 toast。

### H4. 删除/关闭操作无确认对话框

- **维度**：交互
- **位置**：`src/pages/services/index.vue`（删除服务）、`src/pages/products/edit.vue`（删除配置项）、工单关闭
- **说明**：不可逆操作直接执行，无二次确认。
- **影响**：误操作无法撤回。
- **建议**：所有不可逆操作添加 `DialogPlugin.confirm`。

### H5. 品牌色 fallback 错误

- **维度**：视觉
- **位置**：`src/pages/dashboard/base/components/TopPanel.vue` L72
- **说明**：`iconColor` fallback 为 `#0ea5e9`，设计规范品牌色应为 `#165DFF`。
- **影响**：指标卡片图标颜色偏离品牌规范。
- **建议**：将 fallback 改为 `#165DFF`。

### H6. 语义色 fallback 全部偏离规范

- **维度**：视觉
- **位置**：`src/pages/products/index.less` L1648-L1656
- **说明**：
  - `--td-success-color` fallback `#00a870` → 规范 `#12B76A`
  - `--td-warning-color` fallback `#ed7b2f` → 规范 `#F59E0B`
  - `--td-error-color` fallback `#e34d59` → 规范 `#F04438`
- **影响**：产品页状态色与全局设计规范不一致。
- **建议**：统一改为规范色值。

### H7. 字体栈缺失 Inter 和中文字体

- **维度**：视觉
- **位置**：`src/style/reset.less` L10
- **说明**：`font-family: -apple-system, BlinkMacSystemFont, var(--td-font-family)` 缺少规范要求的 `Inter`、`"PingFang SC"`、`"Microsoft YaHei"`。
- **影响**：中文字体回退可能依赖系统默认，不同平台显示不一致。
- **建议**：补齐为 `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。

### H8. LogDetailDrawer 内联 HTML 大量硬编码颜色

- **维度**：视觉
- **位置**：`src/pages/logs/components/LogDetailDrawer.vue` L318-L324
- **说明**：内联 HTML 字符串中含 `#86909c`、`#f5f7fa`、`#1f2329`、`#dce7ff`、`#f8fafc` 等硬编码颜色。
- **影响**：无法跟随主题切换，维护困难。
- **建议**：改为 CSS class + token 变量。

### H9. useListPage 竞态条件

- **维度**：代码质量
- **位置**：`src/hooks/useListPage.ts`
- **说明**：`loadList()` 没有取消前一个在途请求的机制。快速切换筛选条件时，后发起的请求可能先返回，被旧数据覆盖。
- **影响**：列表可能展示错误数据。
- **建议**：引入请求版本号或 `AbortController`。

### H10. ECharts 实例生命周期不完整

- **维度**：代码质量
- **位置**：`src/pages/dashboard/base/index.vue`
- **说明**：`onDeactivated` 中 dispose 了 chart 但未移除 resize 监听。keep-alive 切走时 resize 事件仍触发，对已 dispose 实例调用 `.resize()` 会报错。
- **影响**：控制台静默报错，可能影响性能。
- **建议**：封装 `useECharts` composable，统一管理生命周期；deactivated 时也移除 resize 监听。
