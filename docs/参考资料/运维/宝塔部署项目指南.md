# 宝塔部署项目指南

面向全新服务器的完整部署流程。已有生产环境运维请直接看 [部署与调度指南.md](部署与调度指南.md)。

---

## 一、前置环境

### 1.1 宝塔面板安装

宝塔面板需已安装。未安装参考官方文档，推荐 Linux 系统（CentOS 7+ / Ubuntu 20.04+ / Debian 10+）。

登录宝塔面板后，进入**软件商店**安装以下运行环境：

| 软件 | 版本要求 | 说明 |
| --- | --- | --- |
| Nginx | 1.20+ | Web 服务器 |
| PHP | 8.2 或 8.3 | 项目要求 PHP 8.2+ |
| MySQL | 8.0 | 数据库 |
| Redis | 7.0+ | 缓存 |
| phpMyAdmin | — | 数据库管理（可选） |
| Node.js 版本管理器 | — | 管理 Node.js 版本 |

### 1.2 PHP 关键配置

**安装 PHP 扩展**（PHP → 安装扩展）：

- `fileinfo`
- `redis`
- `opcache`
- `pdo_mysql`

**取消禁用函数**（PHP → 禁用函数 → 删除以下函数）：

- `putenv`
- `proc_open`
- `symlink`

**PHP CLI 版本**：确保宝塔命令行使用的 PHP 与站点一致（宝塔 → 网站 → PHP 命令行版本）。

### 1.3 Node.js 配置

在 Node.js 版本管理器中安装 **Node.js 20.19+**（项目 package.json 约束的最低版本）。

## 二、项目部署概览

生产拓扑如下：

```
宝塔 Nginx
  ├── 站点1: 官网/用户入口 -> frontend-user-v3-www/dist （静态）
  ├── 站点2: 用户控制台   -> frontend-user-v4-console/dist（静态）
  ├── 站点3: 管理端       -> frontend-admin-v3/dist      （静态）
  └── 站点4: 后端 API     -> backend/public              （PHP-FPM）
                              ├── MySQL 8
                              ├── Redis
                              └── 宝塔计划任务（每分钟 php artisan schedule:run）
```

**关键理解**：

- 后端只通过 PHP-FPM 运行，不使用 `php artisan serve`
- 没有常驻 Queue Worker，队列消费并入 `schedule:run`（每分钟）
- 四个站点独立部署，可分配不同的域名/端口

## 三、创建宝塔站点

### 3.1 创建后端 API 站点

宝塔 → 网站 → 添加站点：

| 配置项 | 值 |
| --- | --- |
| 域名 | `api.你的域名.com` |
| 根目录 | `你的项目路径/backend/public` |
| PHP 版本 | PHP 8.2 或 8.3 |
| 数据库 | 新建（后续导入） |

### 3.2 创建前端站点

创建三个前端站点，运行目录分别指向对应 `dist` 目录：

| 站点 | 域名 | 根目录 |
| --- | --- | --- |
| 官网/用户入口 | `www.你的域名.com` | `项目路径/frontend-user-v3-www/dist` |
| 用户控制台 | `console.你的域名.com` | `项目路径/frontend-user-v4-console/dist` |
| 管理端 | `admin.你的域名.com` | `项目路径/frontend-admin-v3/dist` |

## 四、Nginx 配置

以下完整示例以 HTTPS 为例：每个业务站点只监听 `443 ssl`，再为同一域名单独增加一个仅负责跳转的 80 端口站点。证书路径由宝塔 SSL 功能填入。

```nginx
server {
    listen 80;
    server_name api.你的域名.com; # 每个域名各自一段
    return 301 https://$host$request_uri;
}
```

如部署纯 HTTP，删除这段跳转，并把每个示例中的 `listen 443 ssl http2;` 改为 `listen 80;`，删除证书配置；不要配置 SSL、HSTS 或强制跳转，同时将 `SESSION_SECURE_COOKIE=false`。四个公开地址必须同为 HTTP 或同为 HTTPS。

### 4.1 后端 API 站点配置

**站点设置 → 伪静态**：填入 Laravel 伪静态规则：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

**站点设置 → 配置文件**，在 `server` 块中完整替换为以下内容：

```nginx
server {
    listen 443 ssl http2;
    server_name api.你的域名.com;
    index index.php index.html;
    root /www/wwwroot/你的项目/backend/public;

    # SSL 证书（由宝塔 SSL 功能填入实际路径）
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 上传限制
    client_max_body_size 50m;

    # 静态资源直接命中
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot|map|txt|xml|json)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # 预压缩静态资源（构建产物包含 .gz / .br 文件）
    location ~* \.(js|css|svg|json|map|mjs)$ {
        gzip_static on;
        brotli_static on;
        expires 7d;
        add_header Cache-Control "public";
        try_files $uri =404;
    }

    # 禁止访问敏感文件
    location ~ /\.(?!well-known).* {
        deny all;
    }

    # 禁止访问非公开目录
    location ~ ^/(composer\.(json|lock)|artisan|package\.json|\.env) {
        deny all;
    }

    # VNC WebSocket 仅由 API 站点转发到内部 Relay。
    location ^~ /ws/vnc {
        proxy_http_version 1.1;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade           $http_upgrade;
        proxy_set_header Connection        "upgrade";
        proxy_buffering off;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
        proxy_pass http://127.0.0.1:8100;
    }

    # Laravel 主入口
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP 处理
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-82.sock;   # 以宝塔实际 PHP 版本为准
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }
}
```

### 4.2 前端 SPA 站点配置（管理端 / 控制台）

管理端和用户控制台都是 Vue SPA（History 路由模式），需要配置前端路由回退。

以管理端为例（控制台同理，替换域名和路径）：

```nginx
server {
    listen 443 ssl http2;
    server_name admin.你的域名.com;
    index index.html;
    root /www/wwwroot/你的项目/frontend-admin-v3/dist;

    # SSL 证书（由宝塔 SSL 功能填入实际路径）
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;

    # 入口文件不能长期缓存；hash 静态资源可长期缓存。
    location = /index.html {
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    }

    # 官网预渲染页或控制台内的独立 HTML 文件同样不缓存。
    location ~* \.html$ {
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
        try_files $uri =404;
    }

    # 预压缩静态资源
    location ~* \.(js|css|svg|json|map|mjs)$ {
        gzip_static on;
        brotli_static on;
        expires 7d;
        add_header Cache-Control "public";
        try_files $uri =404;
    }

    # 静态资源
    location ~* \.(png|jpg|jpeg|gif|ico|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # SPA 回退：所有非文件请求返回 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 4.3 官网站点配置（含 SSR / 预渲染）

官网站点可能有预渲染的静态 HTML，配置如下：

```nginx
server {
    listen 443 ssl http2;
    server_name www.你的域名.com;
    index index.html;
    root /www/wwwroot/你的项目/frontend-user-v3-www/dist;

    # SSL 证书（由宝塔 SSL 功能填入实际路径）
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;

    location = /index.html {
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    }

    location ~* \.html$ {
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
        try_files $uri =404;
    }

    # 预压缩
    location ~* \.(js|css|svg|json|map|mjs)$ {
        gzip_static on;
        brotli_static on;
        expires 7d;
        add_header Cache-Control "public";
        try_files $uri =404;
    }

    # 静态资源
    location ~* \.(png|jpg|jpeg|gif|ico|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    # SPA 回退
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 五、后端部署

### 5.1 上传代码

将项目代码上传至服务器，例如 `/www/wwwroot/caiwu`。

推荐方式：

- **Git 克隆**：宝塔 → 软件商店 → Git 插件，或手动 `git clone`
- **宝塔文件上传**：压缩包上传后解压

### 5.2 配置 .env

```bash
cd /www/wwwroot/你的项目/backend
cp .env.example .env
```

编辑 `.env`，修改以下必填项：

```ini
APP_NAME="创欧云"
APP_ENV=production
APP_DEBUG=false
APP_KEY=                            # 下一步自动生成
APP_URL=https://api.你的域名.com
FRONTEND_URL=https://www.你的域名.com
CLIENT_CONSOLE_URL=https://console.你的域名.com
ADMIN_URL=https://admin.你的域名.com
CLIENT_SESSION_COOKIE_DOMAIN=.你的域名.com
SESSION_SECURE_COOKIE=true

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=你的数据库名
DB_USERNAME=你的数据库用户
DB_PASSWORD=你的数据库密码

CACHE_STORE=redis
QUEUE_CONNECTION=database
SESSION_DRIVER=file

REDIS_HOST=127.0.0.1
REDIS_PASSWORD=你的Redis密码
```

### 5.3 安装依赖并初始化

```bash
cd /www/wwwroot/你的项目/backend

# 安装依赖（生产环境跳过 dev）
composer install --no-dev --optimize-autoloader

# 生成应用密钥
php artisan key:generate

# 数据库迁移
php artisan migrate --force

# 清缓存并生成生产缓存
php artisan config:clear && php artisan route:clear && php artisan cache:clear
php artisan config:cache && php artisan route:cache
```

### 5.4 设置文件权限

```bash
cd /www/wwwroot/你的项目/backend

sudo chown -R www:www storage bootstrap/cache
sudo chmod -R 775 storage bootstrap/cache
sudo chmod -R 775 public/uploads public/media
```

### 5.5 重启 PHP

宝塔面板 → 软件商店 → PHP → 重启，使生产缓存生效。

## 六、前端部署

### 6.1 构建前端

确保 Node.js 版本满足要求后，在项目根目录只安装一次 workspace 依赖并统一构建：

```bash
cd /www/wwwroot/你的项目
npm ci
npm run build:frontends
# 产物仍分别位于三个前端目录的 dist/，不会写入 backend/public。
```

> 如使用独立 CDN 域名部署静态资源，在各项目 `.env` 中配置 `VITE_ADMIN_ASSET_BASE_URL` / `VITE_CONSOLE_ASSET_BASE_URL` / `VITE_WWW_ASSET_BASE_URL`。默认以根路径 `/` 发布。

### 6.2 验证站点

构建完成后，在浏览器中分别访问四个站点域名，确认页面正常加载，API 请求正常。

## 七、计划任务配置

宝塔面板 → 计划任务 → 添加：

- **任务类型**：Shell 脚本
- **任务名称**：`Laravel 调度`
- **执行周期**：每分钟
- **脚本内容**：

```bash
cd /www/wwwroot/你的项目/backend
php artisan schedule:run >> /dev/null 2>&1
```

> 这条计划任务同时驱动：自动续费、账单逾期处理、服务到期停用、支付回调后的开通队列、推荐返佣异步任务、短信/邮件发送等。不要额外配置 `queue:work`，避免重复消费。

## 八、数据库初始化（可选）

### 8.1 全新初始化

```bash
cd /www/wwwroot/你的项目/backend
python3 scripts/install_db.py
```

### 8.2 从旧库迁移

```bash
cd /www/wwwroot/你的项目/backend
python3 scripts/migrate_legacy_dump.py --dump "你的dump文件.sql" --dry-run
# 确认无误后执行

```

> 执行前务必确认目标库、备份和 `.env`。迁移脚本会修改数据，建议先备份。

## 九、常见问题

### 9.1 502 Bad Gateway

通常原因是 PHP-FPM 未运行或 socket 路径错误：

- 检查 PHP 是否启动（宝塔 → 软件商店 → PHP → 状态）
- 核对 Nginx 配置中 `fastcgi_pass` 的 socket 路径是否与实际 PHP 版本一致
  - PHP 8.2：`unix:/tmp/php-cgi-82.sock`
  - PHP 8.3：`unix:/tmp/php-cgi-83.sock`

### 9.2 页面刷新 404

前端 SPA 站点未配置 Vue Router History 模式的回退规则。在对应站点的 Nginx 配置中确保包含：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

### 9.3 Composer 报 `putenv()` 等函数未定义

宝塔 PHP 的禁用函数列表阻止了某些函数。进入宝塔 → 软件商店 → PHP → 禁用函数，删除 `putenv`、`proc_open`、`symlink`，然后重启 PHP。

### 9.4 上传文件过大

Nginx 默认上传限制 1M，修改站点配置中的 `client_max_body_size`：

```nginx
client_max_body_size 50m;
```

同时检查 PHP 的 `upload_max_filesize` 和 `post_max_size`（宝塔 → PHP → 配置修改）。

### 9.5 定时任务未执行

- 检查宝塔计划任务日志是否正常
- 执行 `php artisan schedule:run` 手动测试
- 确认 `.env` 中 `QUEUE_CONNECTION=database` 且未单独运行 `queue:work`

### 9.6 路由或配置更新不生效

上线后依次执行：

```bash
cd /www/wwwroot/你的项目/backend
php artisan route:clear && php artisan config:clear && php artisan cache:clear
php artisan route:cache && php artisan config:cache
```

然后重启 PHP-FPM（宝塔 → PHP → 重启）。

## 十一、检查清单

部署完成后逐项确认：

- [ ] 四个站点均可通过 HTTPS 访问
- [ ] 后端 API 返回正常 JSON（访问 `https://api.你的域名.com/api/health`）
- [ ] 前端页面刷新不 404
- [ ] 管理端可登录（测试账号见 `AGENTS.md` §六）
- [ ] 宝塔计划任务已添加且正常执行
- [ ] PHP `APP_DEBUG=false`
- [ ] `.env` 中密码均为强密码
- [ ] Redis 可连接（`redis-cli ping` 返回 PONG）
- [ ] `storage`、`bootstrap/cache` 权限为 `www:www` 且可写
- [ ] 数据库迁移已执行无报错
