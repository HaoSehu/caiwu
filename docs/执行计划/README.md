每个计划必须有 YAML 元数据（`status`、`updated`、`owner`）、`## 进度` 和 `## 决策日志`。完成后移入 `已完成/`；未完成但不再排期的工作移入 `技术债/`，不要删除决策依据。例外：一次性、已被真源替代或明确作废的计划允许直接删除，决策依据以 Git 历史与对应真源为准，无需归档副本。

计划 frontmatter 的 `status` 可使用中文值 `进行中`；`docs/catalog.json` 继续使用机器状态 `active` 登记。
