# 执行计划

执行计划是版本控制的一等工件。任何跨模块、迁移、上线或存在回滚风险的工作，先在这里建立计划，再修改实现。

| 位置                                                               | 状态         | 简介                                                |
| ------------------------------------------------------------------ | ------------ | --------------------------------------------------- |
| [已完成/Zjmf统一迁移方案.md](已完成/Zjmf统一迁移方案.md)          | completed    | ZJMF 实时绑定已切换、实例控制已验证，旧插件已卸载且历史已保留。 |
| `已完成/`                                                         | completed    | 已完成计划的保留位置。                              |
| [模板](../模板/exec-plan.md)                                       | template     | 新计划必须采用的最小结构。                          |

每个计划必须有 YAML 元数据（`status`、`updated`、`owner`）、`## 进度` 和 `## 决策日志`。完成后移入 `已完成/`；未完成但不再排期的工作移入 `技术债/`，不要删除决策依据。
