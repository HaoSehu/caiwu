# 命名空间与品牌代号统一方案

## 背景

2026-08-19 对全仓做命名统计，发现同时存在 `caiwu`、`finance`、`chuangouyun`、`coym` 四个名称且未统一。统计结论：

- PHP 根命名空间仅 4 类：`App\`(937)、`Tests\`(291)、`Caiwu\`(71，全为插件)、`Database\`(6)。`finance` 与 `coym` 不是 PHP 根命名空间。
- `caiwu` 是代码侧事实主导代号：插件命名空间 `Caiwu\Plugins\...`（71 文件，无 composer PSR-4 映射，由 `PluginFileLoader` 运行时 require 加载）、前端 npm scope `@caiwu/shared`、配置键 `queue.caiwu_*` 与 env `CAIWU_*`、事件名 `caiwu:login-*`、存储前缀 `caiwu:vnc-credentials:`、默认路径 `/etc/caiwu/`。
- `finance`：仅 composer 包名 `idc/finance`（1 处）+ `App\` 下的业务子域（`App\Services\Finance` 等），属业务领域命名而非品牌命名。
- `chuangouyun`（创欧云）：官方对外产品名（`APP_NAME="创欧云"`、composer description），但代码中仅作 npm workspace 包名 `chuangouyun-*`。
- `coym`：全仓库 0 引用，疑似废弃代号。

目标：确立 `caiwu` 为唯一的「代码内部品牌代号」，消除 composer 包名与 npm workspace 名的孤立不一致，建立命名治理规则。

非目标：

- 不改动已主导且一致的 `Caiwu\Plugins`、`@caiwu/shared`、`queue.caiwu_*`、事件名、存储前缀——遵循 [后端目录分类规范](../../参考资料/后端/后端目录分类规范.md)「不为了整齐一次性大规模移动命名空间」「现有稳定引用路径优先」。
- 不改对外品牌「创欧云」（`APP_NAME`、站点名、UI 文案）。
- 不动 `finance` 业务子域（`App\Services\Finance` 等）——属领域命名，非品牌命名。

## 范围与验收

- [ ] composer 包名统一：`backend/composer.json` `name` 由 `idc/finance` 改为 `caiwu/backend`；`composer dump-autoload` 后 `vendor/composer/installed.php` 的 root name 一致。
- [ ] npm workspace 包名统一：三个前端 `package.json` `name` 由 `chuangouyun-*` 改为 `caiwu-*`。
- [ ] 所有 workspace 引用同步：根 `package.json` scripts、`backend/scripts/build_frontends.mjs`。
- [ ] `package-lock.json` 重新生成，`node_modules/chuangouyun-*` 不再存在。
- [ ] 三端构建通过（`npm run build`：admin/www/console），后端 `php artisan test` 通过。
- [ ] 方案登记：`docs/执行计划/README.md` 索引与 `docs/catalog.json`（status `active`）。
- [ ] `coym` 记为废弃、禁止复用，不产生代码改动。

## 实施步骤

P0（低风险，待确认后实施）：

1. 改 `backend/composer.json` `name` 为 `caiwu/backend`；`description` 保留「创欧云 - Laravel 12」对外品牌展示。
2. 改三个前端 `package.json` 的 `name`。
3. 改根 `package.json` 全部 `--workspace chuangouyun-*` 引用。
4. 改 `backend/scripts/build_frontends.mjs` 的 `workspace` 字段。
5. 重新生成 `package-lock.json` 与 `node_modules`（删除旧 lock 后 `npm install`）。
6. 验证：`cd backend && php artisan test`；三端 `npm run build`；`npm run docs:check`。

P1（技术债，不排期）：

- 保持 `caiwu` 主导命名，禁止回退；`Caiwu\Plugins`、`@caiwu/shared`、`queue.caiwu_*` 等不再改动。

命名治理规则（本方案通过后生效）：

- 代码内部品牌代号统一用 `caiwu`（PHP 命名空间、npm scope、配置键前缀、事件名、存储前缀、包名）。
- 对外产品名统一用「创欧云 / chuangouyun」（`APP_NAME`、站点名、面向用户文案），代码侧不再使用。
- 业务领域子命名空间（如 `App\Services\Finance`）不受品牌代号约束。

## 风险与回滚

- npm workspace 名改动会触发 `package-lock.json` / `node_modules` 变更，可逆；回滚＝恢复 git 中的 lock 与三个 `package.json`。
- composer `name` 为纯元数据，无运行时影响；回滚＝恢复 `composer.json`。
- 事件名、存储前缀、env 键均不动，无运行时兼容风险。
- 提交按项目规则由人工确认（不允许 AI 自动提交）。
