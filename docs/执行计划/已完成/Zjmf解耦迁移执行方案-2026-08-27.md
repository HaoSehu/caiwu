# ZJMF 核心残留解耦迁移执行方案

依据审计产出《魔方财务功能剥离与迁移分析与实施方案书》（2026-08-27 会话内交付）制定，经用户批准按四批推进：P0 门禁核查 → P1 三处核心解耦 → P2 清理 → P3 前端轻量中性化 → P4 测试搬迁与文档收尾。

## 背景

"魔方财务"即智简魔方财务系统（ZJMF）上游对接，旧标识 `mofang_finance*` 已于 2026-07 归档迁移统一为 `zjmf_finance*`，专属逻辑应收敛于 `backend/plugins/servers/zjmf_finance/`。全仓扫描确认核心残留运行时耦合仅 3 处，另有一次性迁移工具、死配置、展示字典与寄居测试需要处置；本系统自有财务域（orders/invoices/payments/余额/返佣）不在剥离范围。历史审计细节与调用链证据见审计书正文，本文件只承载实施进度与决策。

## 范围与验收

- [ ] 核心 `App\` 命名空间下不再出现按 ZJMF 定制的行为分支（登录端点白名单、心跳排除键、任务日志标签）。
- [ ] 一次性工具 `RenameMofangFinanceProviderCommand` 与 `MofangFinanceProviderKeyMigrationService` 删除且 `composer dump-autoload` 后无引用。
- [ ] `config/integrations.php` 的零读取方 `upstream` 配置段删除。
- [ ] 管理端 `useProductShared.ts` 移除 zjmf 字典项、`Suppliers.vue` 文案中性化。
- [ ] 7 个 `Zjmf*Test` 迁入插件独立测试套件并能独立运行。
- [ ] 每批验证通过：backend `composer analyse && composer format:check`、admin-v3 `npm run build`、`npm run docs:check`。
- [ ] 明确保留项不动：`ProviderKey::ZJMF_FINANCE_API`、插件 lib 业务逻辑、`_archive` 四份历史迁移、`.mimosa/hook-state/*.json`、demo 插件参考文案、`.gitignore` 忽略项。

## 实施步骤

1. **P0 门禁**：① 本工件入库；② R1 门禁：`php artisan db:rename-mofang-finance-provider --dry-run` 输出空切换计划并存档临时目录；③ 双库（idc / idc_test）information_schema 全文本列检索 `%mofang%` / `%魔方%` 为 0（只读、值参数绑定）；④ 基线快照 analyse 通过态与 PHPUnit 失败清单。任一不过即中止。
2. **P1-T1 登录端点声明化**：插件新增 `lib/ZjmfLoginEndpointPolicy.php` 并在 Provider 中 tag 至 `upstream.login_endpoints`（复用 `WebSessionCookieParser` 的容器 tag 模式）；核心 `HostingPanelApiTransport::isLoginEndpoint()` 保留 `/v1/login_api` 自有判断、其余改为方法内惰性聚合 tag 声明；插件内部 transport 白名单保留。
3. **P1-T2 心跳排除能力化**：新增契约 `App\Services\Upstream\Contracts\ProvidesSelfStatusSync`；`zjmf_finance/config.php` capabilities 追加、`ZjmfFinanceAdapter` 实现；`CoreScheduledTaskProvider` 的 `service-status-sync` 排除集改为查 enabled 且 capabilities 含该接口的 `integration_plugins` 行（数据驱动），删除 ZJMF 硬编码与注释。
4. **P1-T3 日志元数据动态化**：`AdminLogService` 以惰性 helper 取标题（TASK_META 兜底 registry 任务对象 title），关键词反查源扩为 TASK_META ∪ 各任务 `[title(), key()]`；仅删 TASK_META 的 `refresh-zjmf-finance-auth` 条目。
5. **P2 清理**：R1 双门禁全绿后删除两个 Mofang 文件并 `composer dump-autoload`；删 `config/integrations.php` `upstream` 段；中性化注释六处（ServiceRenewService/ServiceVncService/AbstractUpstreamServerPlugin×5 行段/UpstreamJwtSessionManager/ProvisionService:1502）；重生成 phpstan-baseline 且 diff 限定 AdminLog 相关三条。
6. **P3 前端**：`useProductShared.ts` 删 zjmf_finance_api/zjmf_cloud_api 字典项；`Suppliers.vue` 两处文案中性化；build 验证。
7. **P4 收尾**：新建插件级 `tests/phpunit.xml`，7 个 `Zjmf*Test` 整体迁入（require_once 装载方式不变）；文档口径复核、工件翻已完成并同步 catalog 状态；`npm run docs:check`。

### 回滚有序脚本（R8）

`phpunit.xml.dist` 的 Plugins 套件递归扫描 `plugins/` 且无进程隔离；若 revert 恢复 `tests/Unit/Zjmf*Test.php` 七个同名类而 `plugins/servers/zjmf_finance/tests/` 未随版本库删除，将触发类重复声明致命错误。回滚必须按序执行：

1. 暂停心跳调度观察（可选但推荐）；
2. 删除 `plugins/servers/zjmf_finance/tests/` 及其他随批新增的 untracked 文件（契约、Policy、聚合测试）；
3. `git revert` 对应提交；
4. `composer dump-autoload` 并 `php artisan optimize:clear`。

预防性对冲：本批全部新增文件（两契约、`ZjmfLoginEndpointPolicy`、插件 tests、聚合测试）必须随同一提交入库，任何 untracked 状态都会放大 R8。
