# 推广大使功能：会员等级返利剥离

## 背景

会员等级原本同时承载价格折扣矩阵（等级 × 营销组）与邀请返利比例（`member_levels.reward_rate`）。业务上邀请返利与"会员身份档位"无关，需求要求等级只保留折扣与身份语义，把返利比例剥离为独立的"推广大使"档位功能，并完整继承现有邀请返利链路（冻结、释放、冲正、提现）。

## 范围与验收

- [x] 新表 `promotion_ambassadors`（名称/返利比例/状态/备注）+ `users.promotion_ambassador_id` 外键（SET NULL）。
- [x] `member_levels.reward_rate` 迁移删除；等级 CRUD、资源输出、前端表单不再含返利比例。
- [x] 返利结算费率来源切换：`users.promotion_ambassador_id → promotion_ambassadors.reward_rate`，未指派回退全局 `referral.reward_rate` 设置（默认 10%）。
- [x] 管理端推广大使 CRUD API（`promotion_ambassador.list/manage` 权限）与页面（用户详情页新增"推广大使"下拉指派）。
- [x] 客户端推广中心输出 `current_ambassador`/`ambassadors` 替代 `current_member_level`/`member_levels`；v4-console 展示大使名与比例。
- [x] Feature 测试：大使 API 9 例、指派 4 例、返利费率 3 例；全量 Feature 33/33 通过。
- [x] 生成物刷新：DATABASE.md（68 表）、后端 API 清单（364 接口）、管理端 apiCatalog（362 条）。

## 实施步骤

1. 迁移三连（000008 建表+默认大使 / 000009 users 加列 / 000010 删等级返利列），idc 与 idc_test 双库执行。
2. 后端：`PromotionAmbassador` 模型与 `PromotionAmbassadorService`（对标 MemberLevelService：缓存列表、重名校验、删除守卫）；`ReferralService` 费率解算与 overview 改造；`UserService::adjustPromotionAmbassador`。
3. 管理端 API：`PromotionAmbassadorController`、Requests、Resources、路由与权限（marketing_growth 组）。
4. 前端：admin-v3 新增推广大使页面与菜单、等级页移除返利比例、用户详情页大使下拉；v4-console 推广中心改大使展示。
5. 测试与生成物刷新，双库迁移验证。

## 风险与回滚

- 存量用户 `promotion_ambassador_id` 为空，回退全局比例，线上费率不变（默认大使 10% 与全局默认一致，属兜底冗余）。
- `referral_rewards.reward_rate` 为历史快照字段，保留不改；退款冲正、提现链路零改动。
- 回滚仅需 revert 三个迁移（down 已实现）与代码；等级 `reward_rate` 列 down 可恢复（历史比例值不可恢复，需人工补配）。
