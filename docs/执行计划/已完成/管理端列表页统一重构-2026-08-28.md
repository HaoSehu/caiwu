# 管理端列表页统一筛选列表页重构-2026-08-28

## 背景

管理端（frontend-admin-v3）13 个"筛选 + 后端分页"列表页各自手写列表状态三件套（loading/list/total/filters/pagination + loadList + buildParams + keep-alive 刷新），重复约 2500–3500 行；详情抽屉状态在账单/充值页重复约 140 行。目标：按 TDesign「筛选列表页」模式统一为 `useListPage` 引擎 + 共享组件，清除重复并补齐 keep-alive 回页刷新、错误态统一、财务三页体验升级（日期范围 + 快捷筛选 + URL 同步）。

参考蓝本为 v4-console 已上线的 `useRecordList` + `dateFilters` + `RecordQuickFilters` 同模式重构。

## 范围与验收

- [x] `useListPage` 增强：新增可选 `afterLoad / syncUrl / enableQuickFilter`，严格向后兼容（订单页既有用法零破坏）。
- [x] 新建 `domains/finance/dateFilters.ts`（快捷日期单一真源）与 `components/quick-filter-tags`（快捷标签组件）。
- [x] 财务三页（订单/账单/充值）：双日期框换 `t-date-range-picker`、快捷标签行、URL 同步；账单/充值详情抽屉接入 `useFinanceDetailDrawer`（新增可选 normalize 参数）。
- [x] 其余 10 页接入引擎：users/tickets/services/content/referral（双引擎实例）/coupons/coupon-campaigns/staff/VerificationPanel/logs（单引擎 + Tab 白名单）。
- [x] 分页形态统一：users/verification/staff 从表格内嵌改为表格下方独立 t-pagination。
- [x] 顺手修复 users 页 `#balance` 死代码插槽（colKey cash_balance 未命中，桌面端金额未格式化）。
- [x] 每批 `npm run build`（vue-tsc + vite build）全绿，最终全量构建通过。

## 风险与回滚

- 无后端改动，API 参数命名不变（page/page_size/keyword/status/type/start_date/end_date）。
- orders 页已用 useListPage，增强保持签名与默认行为不变，避免回退。
- 行为变更均为改进方向：接入引擎页面自动获得 keep-alive 回页刷新；错误态统一为 toast + 保留旧列表（tickets 原清空、users 原静默）；财务三页 URL 查询参数变化（刷新/分享自动恢复筛选）。
- 超大页（ProductCatalog/Suppliers）与非分页小列表（roles/specs 等）未触碰。
- 回滚条件：任一页面功能回归，按页面 diff 单独回退即可，引擎接口向后兼容。
