# 会员等级产品组折扣矩阵计划

## 背景

参考 ZJMF 智简魔方（`zjmf-manger-decoded-main`）的「客户组 × 产品组」折扣矩阵方案，为 caiwu 的会员等级补上价格权益。现状：等级只挂钩分销返利率（`reward_rate`），与商品定价零耦合；系统内不存在客户分组概念。

## 目标口径（已确认决策）

1. 客户维度复用 `member_levels`，不新建客户组。
2. 产品组维度新建独立营销分组，不复用三级目录分组；一个商品可归多个营销组。
3. 折扣类型：type=1 百分比（bates 语义：value 为折后保留比例，如 90=九折）＋ type=2 固定金额减免（下限 0）。
4. 生效范围：新购 + 续费；升级差价本期不动。
5. **2026-08-27 追加：等级完全手工化**——不再设置累计销售额上限/下限与等级编码，删除自动定级链路，等级由管理员在用户详情页直接指定。

## 决策日志

| 日期 | 决策 | 理由 |
| --- | --- | --- |
| 2026-08-27 | 复用 member_levels 作客户维度，不新建 client_groups | 自动定级与 users 外键已就位，避免双身份体系 |
| 2026-08-27 | 营销分组独立成表，不挂 third_product_groups | 与 ZJMF 对齐，圈品灵活且不动现有目录语义 |
| 2026-08-27 | 百分比采用 ZJMF bates 语义（折后保留） | 用户指定对齐 ZJMF；与优惠券 percentage（减免式）语义相反，代码注释需显著标注 |
| 2026-08-27 | 生效范围=新购+续费；升级不动 | 升级差价由上游面板报价、本地现为固定 0 折扣，改动风险大 |
| 2026-08-27 | 对 subtotal 整笔打折（含配置项加价与安装费），不分账期周期 | 计算透明简单；ZJMF 亦按整单金额打折 |
| 2026-08-27 | 同商品多营销组命中时取最终价最低的规则 | 规则确定、不会坑用户，避免 ZJMF find() 无序取值的问题 |
| 2026-08-27 | **等级完全手工化：删除 code/sales_amount_min/sales_amount_max 与自动定级链路（resolveLevelBySales/syncUserLevel/ensureUserLevel），user 上 member_level_source 一并删除** | 用户明确要求不再设置销售额门槛与等级编码；等级由管理员直接指定。连带影响：返利比例按用户当前等级取；推广中心 next_member_level（升级提示）随之移除；用户端推广中心响应不再含 code/门槛字段 |
| 2026-08-27 | **再精简：删除 sort_order 排序值字段** | 用户明确要求；等级列表按 id 排序，营销产品组（marketing_product_groups.sort_order）不受影响 |
| 2026-08-27 | 手工调级=设置等级/置未分级（PATCH member_level），无"恢复自动"概念 | 已无自动定级来源，来源锁机制失去意义 |
| 2026-08-27 | **返利比例剥离：等级不再承载邀请返利，费率改由推广大使档位（promotion_ambassadors）承载** | 邀请返利与会员身份权益解耦；详见 [推广大使功能与等级返利剥离-2026-08-27](推广大使功能与等级返利剥离-2026-08-27.md) |
