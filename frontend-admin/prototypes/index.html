管理端移动端适配原型

以下原型展示了管理端在手机端（≤900px）的 UI 适配效果，包括统一的圆角、间距、配色和交互模式。
建议在 Chrome DevTools 中切换到手机视图查看。

原型页面
列表页 核心
用户管理列表 — 筛选区、表格横滑、次要列隐藏、分页精简、侧边栏抽屉
›
仪表盘
指标卡片网格、统计条、收入趋势、最近账单、待处理工单
›
登录页
品牌展示、登录卡片、表单布局、按钮样式
›
详情抽屉 + 表单 交互
工单详情抽屉、描述列表、操作表单、沟通记录时间线
›
设计要点
统一设计 Token
  • 卡片圆角 8px，弹窗/抽屉 12px，按钮/输入框 6px
  • 按钮最小高度 36px，登录按钮 44px
  • 页面骨架间距 20px，卡片内间距 16-18px
  • 统计数值字号统一 24px
移动端适配策略
  • 断点统一为 900px（平板/手机分界）和 640px（小屏）
  • 筛选区输入控件 100% 宽度，纵向排列
  • 表格 横向滚动 + 滑动提示，次要列通过 .col-hide-tablet 隐藏
  • 弹窗/抽屉 近全屏（900px 以下 92vw，640px 以下 96vw）
  • 分页精简：隐藏每页条数和总数，只保留翻页按钮
  • 侧边栏改为 抽屉导航（min(280px, 80vw)）
查看方式
  • 在 Chrome 中打开任意原型页面
  • 按 F12 打开 DevTools
  • 点击设备切换按钮（或按 Ctrl+Shift+M）
  • 选择 iPhone 或 Android 设备预览
  • 也可以直接拖动浏览器窗口到手机宽度查看
